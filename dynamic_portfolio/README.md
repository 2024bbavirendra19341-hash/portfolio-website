# Dynamic Digital Marketing Portfolio

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

No build tools or frameworks required.

## Customize before publishing
- Replace `Virendra Soni` and the `virendra.` logo text with your preferred brand/name.
- In `index.html`, change `hello@example.com` to your real email. Update it in both the visible email link and the contact form destination in `script.js`.
- Replace the Instagram and LinkedIn `href="#"` links with your real profile URLs.
- Replace the three illustrative portfolio concepts with real projects and results. Do not present the sample stats as verified business results.
- Update the meta description and page title to match your business.

## Features
- Responsive layout and mobile navigation
- Light/dark theme toggle (saved in browser local storage)
- Scroll progress bar and reveal-on-scroll animations
- Animated stat counters
- Filterable project cards
- Contact form that opens a prefilled email (no backend/database)
- Reduced-motion accessibility support

## Publish
Upload the three files (`index.html`, `style.css`, `script.js`) to a static hosting service such as GitHub Pages, Netlify, or Vercel.
